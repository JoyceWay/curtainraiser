《Solo Founder AI 手册》v1.0 · 学习计划 2.0（2026-10-03 定）。
每天 4 小时 = 3.5h 新课 + 0.5h 输出/复习，每周 6 天，低摩擦、可执行。
目标：建一个产品，变现。

学到哪一章，那一章的资料就进资料库。

阶段一 · PHASE 1 · 6–7 周 · 123H

跑通

先成为能独立干活的人，再谈赚钱。每一章都必须回答"这章怎么帮我赚钱"，答不上来的不学。

  • 前置 · 工具与网页三件套（25h）——P0 AI 结对编程 4h · P1 HTML 3h · P2 CSS 6h · P3 JavaScript 12h
  • Part A · 地基（22h）——LLM 怎么"想" · Context engineering · 结构化输出＋embeddings · 第一次调 API · RAG 一章讲透
  • Part B · Agent 实战（36h，全书最厚）——Agent＝模型＋脚手架 · 第一个单 agent · Skills · 工具设计 · 记忆与状态 · 多 agent 铁律
  • Part C · Eval 与 Loop（16h）——Eval 怎么知道变好了 · Loop engineering · 长任务脚手架
  • Part D · 一人公司商业（24h）——四种赚钱模式 · 定价 · 获客 · 技术栈只买不造 · 验证与避坑
