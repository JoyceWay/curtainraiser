召唤师图鉴：我现在能召唤的全部法力

Every AI she can actually call on in October 2026 — what each does, what it costs, and which few are worth adding. 配套：《召唤师手册》 · 《顶级召唤师》

1. 总论：缺的不是模型，是分工

全景

2026 年 10 月，四家的竞争轴心已经从「谁的模型最聪明」变成「订阅里打包了什么」：价格带统一收敛到 $8 / $20 / $30 / $100–200 四段，模型之间是各有所长，不是谁碾压谁。

所以她的法力缺口不在数量，在三处：① 已付费的装备没用满；② 缺一支不同家族的施工队（会诊和备份都靠它）；③ 缺几个专长召唤物（搜索、短剧视频、配音）。本图鉴逐个点名、标价、定岗位，最后给新增排序和两套配置。

口径：2026-10-22 四路调研（前沿 / 专长 / 创意 / 仆从）+ Gemini 会诊（Flash 已回，Argon 盲评待补）+ Muse 终审。价格为美国区月价，变动极快，付款前以官网为准；未核实处文中标注。

法力不在召唤得多，在分工得清、验收得住。

By October 2026 the frontier race is no longer about the smartest model — it is about what each subscription bundles. Her gaps are not numerical: paid gear she underuses, no second model family for cross-checks and backup, and a few missing specialists. This bestiary names, prices, and assigns every summon she can actually call.

2. 在役阵容：已经付了钱的法力

已有

  • Gemini 订阅（现役主力）——Gemini 4 Argon（2026-09-30 发布，付费档可达）+ Antigravity + NotebookLM 高配 + Nano Banana Pro 生图 + Flow 每月 1,000 积分（Veo 3.1 视频）。档位已确认：Google AI Pro，学生免费一年（2026-10-22 她本人确认——在读身份的免费年，年内 $0，到期后按 $19.99 / 月续；到期日建议她查一眼订阅页，心里有数）。两个提醒：Flow 积分按月清零，不用就是白扔；Argon 在 Gemini App 内 Pro 档可达，Antigravity 内的 Argon 官方口径挂在 Ultra 名下——她手工调用 Argon 的实际入口以她为准，不影响本图鉴的配置测算（§8 按 Pro 价算）。
  • X Premium $8（祖父档，别退）——2026-10-12 xAI 把 Grok 与 X 订阅合并成新体系（Plus $8 / Premium $30 / Super $100 / Ultra $200，全家共用一个周额度池）。她这份旧档按原价原权益保留：X 内 Grok 上限约为免费档的 4 倍量级（官方未公布精确条数）。退了就买不回来。
  • Muse（经本应用，总指挥在役）——但没有 Claude 付费订阅，就等于没有 Claude Code、没有 Cowork、没有 Opus 直连。这是 §7 把 Claude Pro 排第一的原因。
  • 免费在役——NotebookLM 免费额度、DeepSeek / Qwen 免费聊天（只聊天，敏感内容不进消费版 App，见 §4）。

Already paid for: a Gemini subscription — confirmed tier Google AI Pro $19.99 (Argon, Antigravity, high-tier NotebookLM, Nano Banana Pro, 1,000 monthly Flow credits that expire unused), a grandfathered $8 X Premium (never cancel — it cannot be bought back after the October 12 plan merger), and Muse via this app — but no Claude plan, which means no Claude Code, no Cowork, no direct Opus.

3. 四大前沿图鉴

前沿

  • ChatGPT（GPT-6.1 Sol，Plus $20）——岗位：全能副手 + 语音陪练。独门：实时语音四家最成熟（GPT-Live，练口语正对口）；Plus 含 Codex 云端派活和办公 agent（Work）。坑：Sora 已于 2026-09-24 彻底关停，别再拿它规划视频；型号换得最快，教程最容易过期；免费 / Go 档带广告。
  • Claude（Opus 5.5 / Fable 5.1，Pro $20）——岗位：长文与逻辑终审 + 第二施工队。独门：Artifacts + Projects；Pro 档直接含 Claude Code，四家唯一；Cowork 桌面 agent 最贴「指挥型」用户。坑：限额最不透明（5 小时窗 + 周上限双重计量），重度使用要 Max $100 起；Fable 在 Pro 上另烧 credits；无原生生图 / 视频。
  • Grok（4.7，她的 $8 旧档已覆盖基础）——岗位：X 实时雷达。独门：唯一原生吃 X 全量信息流的模型——热帖、舆情、正在发生什么，无对手；Imagine 生图 + 图转视频，尺度最宽。坑：新体系额度只给倍数不给数字；写作与施工不是最强项；常驻 agent（Grok Bot）要新 Premium $30 才含。裁决：基础档够用，不升级。
  • Gemini（4 Argon，已订阅）——岗位：现役主力 + 生态中枢。独门：一个订阅打包搜索 AI Mode、Gmail / Docs 内嵌、5 TB 存储、NotebookLM、Veo——单是存储（2 TB 单买 $9.99）就回本一半；API 价格四家最低。坑：最强能力被 Ultra 分档墙挡住一部分；限额是「算力制」，不透明。

The big four, assigned: ChatGPT (GPT-6.1 Sol) — all-rounder plus the best voice mode for speaking practice; Codex included at Plus; Sora is shut down for good. Claude (Opus 5.5 / Fable 5.1) — long-form judgment and the second build crew; Pro uniquely bundles Claude Code; quotas are the murkiest. Grok (4.7) — the X real-time radar, already covered by her $8 legacy plan; do not upgrade. Gemini (4 Argon) — the incumbent hub whose bundle (search, mail, storage, NotebookLM, Veo) pays for itself.

4. 专长召唤物：搜索、学习与国产模型

专长

  • Perplexity（免费可打，Pro $20）——引用优先的答案引擎，是查证工具不是写作工具。独门是 Focus 模式：查痛点切 Social（只搜论坛与社媒）、查论文切 Academic——这一步比升 Pro 更值钱，免费档就有。Pro 给不限量 Pro Search 与 Deep Research；Max $200 买的是额度与多模型会诊，不是「更真的答案」，不买。
  • NotebookLM（她订阅内已提额）——只读你给的资料的学习机：回答严格限定在信源内并标引用，幻觉最低。把长文、访谈、论文喂进去，生成双人播客讲解、闪卡、测验、思维导图。这是全场最常被漏掉的一格法力——「读不懂」的问题，一半靠它解决。
  • DeepSeek（API 按量，月均几美元）——正确打开方式是 API，不是 App。V4 系列谷时入价约 $0.15 / 百万 token，比旗舰便宜约一个数量级，还带缓存折扣；批量杂活、逻辑挑刺走它。红线：数据合规是真雷区（2026-10-19 美国 DHS 下令联邦机构移除；普通公众在美国使用仍合法），敏感内容不进消费版 App，走 API 或美国境内部署。
  • Kimi（会员 $19 起）——国产里综合体验最「国际化」：1M 上下文、中文长文理解第一梯队、美国可直达，自带 agent 与深度研究。坑：积分池把聊天 / 研究 / 编程混在一起烧；消费版隐私政策写明对话用于训练且无退出选项——机密不放。
  • Qwen（聊天免费免注册）——开放权重最彻底的家族（大量 Apache 2.0 可商用），价值在「到处都是它」：无数第三方工具内置，你常常已经在用而不自知。不必专门订阅，知道它在那儿即可。
  • GLM / 豆包 / Meta AI / Copilot 裁决——GLM 是程序员向的平替引擎，与她的工作流不重叠，略过；豆包本体美国区被锁（海外版对美锁定），用不上，它的 Seedance / Seedream 将来可经第三方 API 间接调用；Meta AI 自 2025-12 起对话默认用于广告定向，商业想法别在那儿聊；Copilot 只有重度 Office 用户才值，她不买。

Specialists: Perplexity is a citation-first research tool — its Focus modes (Social for pain points, Academic for papers) matter more than the Pro tier. NotebookLM is the most-missed power in the whole list: a source-bound study machine that turns long reads into podcasts, flashcards, and quizzes. DeepSeek's value is its API (an order of magnitude cheaper), not its consumer app. Kimi is the most international Chinese model; Qwen wins by being everywhere for free. GLM, Doubao, Meta AI, and Copilot all get a pass, each for a stated reason.

5. 创意系图鉴：图、视频、声音

创意

图像

  • Nano Banana Pro（Gemini 3 Pro Image，她订阅内已含）——综合首选：改图保主体的一致性最强、图内短文字约 95% 准、API 可出 4K。卡面美术与封面改图，先走它。
  • Midjourney V8.1（$10 起）——美学天花板，「第一眼哇」的封面氛围图仍是标杆。短板：图内文字差、默认公开（Pro 档才私密）、无免费档。按需月订，不必常驻。
  • Ideogram 4.0（$20）/ Recraft V4.1（$10 起）——带文字的设计（海报、标题图）找 Ideogram；要可编辑 SVG 矢量与成套品牌资产找 Recraft。
  • Flux 2 / Grok Imagine——写实标杆与宽松尺度的梗图，各备一格即可；Imagine 她的 X 档内就有额度，不必另付。

视频

  • Kling 3.0 可灵（国际版 Standard 约 $10 起）——姐姐短剧的主力：一次最多 6 个连贯镜头、参考图锁脸锁服装、原生音频 + 多语种唇形。关键一条：中美两边都能直连，姐姐在国内可直接用，省掉整套跨境执行的复杂度。积分烧得快，按生产节奏上 Pro（约 $33）。
  • Veo 3.1（Flow，她订阅内）——单条质感与原生声音首选。每月 1,000 积分 ≈ 10 条 Quality 或 50 条 Fast——先把每月送的积分用满，再谈买别家。
  • Hailuo H3（MiniMax，约 $10.5 起）——参考驱动的编辑与性价比，国内可用，姐姐的第二选择。Runway Gen-4.5（$15 起）是专业工作流与多模型聚合，等真有剪辑量再说。附注：字节 Seedance（即梦）在国内短剧圈口碑极强、角色一致性出众，姐姐可一并试（细节未核实）。
  • ⚠️ Sora 已停运——App 2026 年 4 月关闭、API 9 月 24 日下线，OpenAI 无继任视频产品。旧教程、旧价格一律作废。

声音

  • ElevenLabs（Starter $6 / Creator $22）——配音与声音克隆的默认答案，90+ 语言，克隆音色可跨语种说话。姐姐短剧的角色配音走它。
  • ChatGPT 语音 / Suno（Pro $10）/ NotebookLM 音频——语音是陪练（练口语），不是配音生产；Suno 管音乐，注意 2026-09 起下载数成了新瓶颈；NotebookLM 音频概览管「听懂资料」，免费。

Creative bench: Nano Banana Pro (already in her Gemini plan) is the all-round image pick; Midjourney rents the aesthetic ceiling by the month; Ideogram and Recraft cover text-in-image and editable vectors. For video, Kling 3.0 is the sister's drama workhorse — multi-shot consistency, and it works natively in both the US and China; Veo 3.1 in Flow is already paid for, so burn the monthly credits first. Sora is dead — retire every old tutorial. ElevenLabs owns voice; ChatGPT voice is a speaking coach, not a dubbing studio.

6. 仆从系图鉴：agent、bots 与编程

仆从

  • Antigravity（在役主力，增量成本 0）——agent 优先的指挥台：多 agent 并行、产出可核查的 artifacts，与她的「派活—验收」打法同构。提醒：产品仍新、额度规则变动频繁，重要仓库留 git 备份，别把唯一生产流程全押一家。
  • Claude Code（含在 Claude Pro $20）——不同家族的第二施工队 + 代码终审。这正是 §7 第一名的核心理由：买的不是聊天，是冗余与会诊。
  • Codex（含在 ChatGPT Plus $20）——云端批量派活型：把边界清楚的小任务排队丢出去，回来逐个验收 PR。与指挥官模式合拍；若订 Plus，它和语音是两根付费支柱。
  • Cursor / Windsurf / Copilot（不买）——编辑器型工具，价值大头属于「坐在编辑器里写代码的人」；她不坐编辑器，边际价值打三折。且 Cursor 2026-10-12 起并入 X 订阅体系、与 Grok 共用额度池，账更难算。
  • Replit Agent（Core $25）——零配置出原型本类最快，但 agent、算力、部署共用一个 credit 池，失败的尝试也扣费——偶尔验证想法可以，不做长期产品的家。
  • Manus（$20 起）/ Genspark（$25）/ Lindy（$30 起）——Manus 最像「多雇一个助理」，成套调研与一次性小网站能交活，但费用不可预估、无预算护栏，只当偶尔外包；Genspark 是交付物杂货铺（报告、幻灯、表格一站出），成品只算第一稿；Lindy 管行政自动化（邮件分诊、会议跟进），功能真实，但她现在的业务量喂不饱它——时机未到。
  • Devin（明确不买）——它假设你已有正经仓库、CI 和审 PR 的工程纪律；探索期「做出来、看一眼、推翻一半」的循环，恰恰是它烧钱最快的形状。等有稳定仓库和明确 backlog 再议。
  • Poe（$19.99）/ ChatHub（约 $19）——会诊弹药库二选一：Poe 胜在模型全（100+ 模型与自建 bots，冷门模型当陪审），ChatHub 胜在同屏并排（一次最多 6 个模型，正是她的会诊习惯）。会诊量大了再买一个，先用免费档。
  • Make / n8n（自动化）——第一条真流水线（订单通知、内容分发）出现时，先用 Make 练手（免费 1,000 credits / 月，模板多）；复杂了再迁 n8n（自托管近乎免费，但要自己运维）。现在先收藏，不启用。

The servant class: Antigravity stays the command deck at zero marginal cost. Claude Code (inside Claude Pro) is the second crew from a different family; Codex (inside ChatGPT Plus) takes queued, well-scoped tasks. Editor-centric tools (Cursor, Windsurf, Copilot) lose two-thirds of their value for a director who never sits in the editor. Replit rents speed at unpredictable credit cost; Manus is an occasional contractor, not staff; Genspark and Lindy are real but premature; Devin is a clear no. Poe and ChatHub are the consultation armory — buy one when consultation volume justifies it. Make first, n8n later, when the first real pipeline exists.

7. 新增召唤排序（带分数）

决策

  • 1 · Claude Pro $20 — 9 分：一笔钱买三样：第二施工队（Claude Code）、桌面仆从（Cowork）、异族终审脑（Opus / Fable 直连）。她的系统冗余从 0 到 1，就差这一笔。
  • 2 · DeepSeek API 约 $3 / 月 — 8.5 分：不是订阅是按量。批量杂活与挑刺的成本砍一个数量级，专职廉价杂役。
  • 3 · Kling（姐姐线，$10 起）— 8.5 分：这是给短剧生产线的投资，不记她的工具账；国内直连一项，就值回票价。
  • 4 · ChatGPT Plus $20 — 7.5 分：买的是语音陪练（她要练口语，这是四家最成熟的）+ Codex 派活。扣分项：与 Gemini 重叠面最大，且会诊里有「浪费」裁决（见 §9）——值不值，取决于她练口语的决心有多真。
  • 5 · Perplexity Pro $20 — 7 分：先免费跑两周，Focus 模式先用起来；当「查痛点、查竞品」变成每周固定动作，再升 Pro。
  • 6 · ElevenLabs Starter $6 — 7 分：等姐姐短剧进入配音阶段再开，小钱大用。
  • 7 · ChatHub 或 Poe $20 — 6.5 分：会诊弹药库，等会诊频率上来再二选一，现在买是闲置。

The summoning order: Claude Pro first (9/10) — one payment buys a second crew, a desktop servant, and a foreign-family judge. DeepSeek API (8.5) for near-free grunt work. Kling (8.5) belongs to the sister's production line. ChatGPT Plus (7.5) is really a voice coach plus Codex. Perplexity Pro, ElevenLabs, and a consultation gateway follow, each gated on a real trigger rather than curiosity.

8. 两套法力配置

配置

  • 省钱版 ≈ $31 / 月（学生年内）：Gemini Pro $0（学生免费年）+ X Premium $8（已在付）+ Claude Pro $20（新）+ DeepSeek API 约 $3（新）。新增支出 $23，法力结构从「单核」变「双核 + 廉价杂役」；学生年到期后续上 Gemini 的 $19.99，总价回到约 $51。
  • 全力版 ≈ $146 / 月（学生年内，到期后约 $166）：省钱版 + ChatGPT Plus $20 + Perplexity Pro $20 + ChatHub / Poe $20 + ElevenLabs Creator $22 + Kling Pro 约 $33（姐姐线）。每一格都有明确岗位，没有一件是「买了再说」。
  • 中间态（推荐走法）：先上省钱版，跑一个月看账本——哪格额度先见底，哪格就是下一笔钱的去向。用额度账说话，不靠想象加购。

Two loadouts: the lean build (~$31/mo during her free student year, only $23 of it new) turns a single-core setup into dual-core plus cheap labor. The full build (~$166/mo) fills every specialist seat. Recommended path: run the lean build for a month and let the quota ledger — not imagination — decide the next purchase.

9. 会诊分歧（事实与观点分开）

会诊

  • 分歧一 · ChatGPT Plus：Gemini Flash 裁「完全浪费」（观点）；调研事实是语音与 Codex 均为独门、无替代。Muse 终审：Flash 的判断对纯聊天用户成立，对「要练口语 + 要派活」的她不成立，7.5 分维持。
  • 分歧二 · Poe：Flash 裁「智商税」（观点）；调研显示它是冷门模型陪审的最低成本入口。Muse 终审：她现阶段会诊量不大，两边各对一半——先免费，不付费。
  • 分歧三 · Cursor：Flash 称它是「自然语言指挥写产品的唯一工业级工具」（观点）；四路调研一致认为它是编辑器型工具，且新定价已并入 X 订阅体系。Muse 终审：她的主场是指挥台不是编辑器——不买。
  • 三方共识：Claude Pro 是第一新增；Grok 不升级（实时雷达的价值在「有」，不在「多」）；多模型协作最危险的坑是传话失真（见 §10）。
  • Argon 盲评 · 共识区：它独立给出的判断里，与图鉴一致的有：Grok 不升级（理由几乎同词）；Kling 是短剧第一梯队（它排总榜第 1，图鉴放姐姐线第 1——会计口径不同，判断相同）；NotebookLM 零成本必用；Manus / Genspark 现阶段不值。三方军师在这些格子上完全同构。
  • Argon 盲评 · 最大分歧：Claude Pro：它把 Claude 官方订阅直接列进浪费清单，理由是「已有 Muse（本应用）+ Antigravity + Gemini 已覆盖，偶发高阶需求走 OpenRouter 按量，每月花不到 $2」。Muse 终审分两层：模型层它对——纯聊天、长文调用，OpenRouter 按量确实便宜得多，为聊天开 $20 订阅是浪费；产品层它错——Claude Code 与 Cowork 是 agent 产品（读全仓改代码、操作本地文件），OpenRouter 只给模型 API，给不了这两个，她经本应用使用的 Muse 也不等于 Claude.ai 的 Projects / Artifacts。裁决：§7 第一名维持，但理由收窄为「只为 Claude Code + Cowork 付钱」；下周试用若发现她只拿它聊天，立即降级为 OpenRouter 方案——试用三件事正是为此设的闸。
  • Argon 盲评 · 分歧：ChatGPT Plus：它列浪费，图鉴给 7.5 分。差在一个权重——它没把「练口语」计入她的目标清单。维持 7.5，注脚不变：值不值取决于练口语的决心。
  • Argon 盲评 · 它捞回来的：OpenRouter、Lovable / Bolt、即梦、Exa / Felo——四路调研的真遗漏，核实后补入 §11。它还给 ElevenLabs 加了一个图鉴漏掉的用法：单词卡朗读（产品 roadmap 的 ② 号功能本来就是发音按钮）——这一条认账，它的 $5 入门档口径与调研的 $6 差 $1，以官网为准。它的两套配置（省钱 ≈ $23–28、力 ≈ $113）与图鉴的差异只在「算不算已有订阅」的口径，分工判断大体同构；唯一真正的路线分歧就是 C 位给 Kling 还是给 Claude Pro，留给她的试用数据裁决。

Where the council disagreed: Gemini Flash called ChatGPT Plus a total waste and Poe a fool's tax, and crowned Cursor the one industrial tool — the research record and the final review side against all three, for stated reasons (voice and Codex are unique; Poe is the cheapest jury pool; Cursor serves people who sit in editors). Consensus held on Claude Pro first, no Grok upgrade, and the relay-distortion pitfall. Argon's blind review is still out; it will be appended here, unedited.

10. 一个坑：交接不设闸——传话失真 + 格式雪崩

协议

Flash 的原话要点：把 A 模型的输出直接复制给 B 继续做，B 会默认 A 全对，顺着细微的逻辑漂移一路推下去，最终南辕北辙——模型有讨好倾向，接棒者不天然质疑上一棒。

这正是她的协奏协议 (2)「文件就是会议室」要防的事：AI 之间不传话，只读写提炼过的规格文件；人做状态机，剔掉修饰词再喂下一棒。手册已经写对了，图鉴只负责给新成员立规矩：每一个新召唤的 AI，入职第一件事是读标准文件，不是读上一位的聊天记录。

Argon 从完全不同的方向撞上同一个坑，它的那层叫格式契约雪崩：A 输出的字段名一会儿是 word、一会儿是 vocabulary，层级和标点每次都抖，B 写好的代码就频频崩——非程序员看不懂报错，只会误判「AI 写代码太蠢」，陷进无休止的修 bug 循环。它的解法是「Schema 闸口」：模型之间流转的数据一律写死 JSON 契约，字段名不许漂移。合并裁决：这是同一个病根的两层——语义层的意思会漂，结构层的格式会抖。而她其实已经在做了：单词卡的 l1-60.json 就是数据合同，断行点逐字对齐就是闸口。两位军师绕了一圈，撞上的是她自己的实践。以后新流水线立项，先问两句：意思会不会漂？格式会不会抖？

召唤的礼仪：先读标准，再接活。传话会失真，文件不会。

The one pitfall every source agreed on: relay distortion. Paste model A's output into model B and B treats it as gospel, compounding small drifts into a wrong destination. Her protocol already answers it — AIs never relay messages; they read and write distilled spec files, and the human stays the state machine. Every new summon reads the standards first, not the previous model's chat log.

11. 补遗：盲评捞回来的名字

补遗

  • OpenRouter（按量，无月租）— 8.5 分：一个 API key 调 500+ 模型，价格 = 各家原价透传 + 充值时 5.5% 手续费，另有免费模型池（已核实，2026-10）。岗位：召唤冷门模型、临时评测、给产品接多模型的统一底座。定位校准：它替代的是「为模型开订阅」，替代不了 Claude Code 这类 agent 产品；DeepSeek 直连 API 比它再省那 5.5%，它胜在广度。排位上它插在 §7 的第 2 名与第 3 名之间——API 层的召唤，归它管。
  • Lovable / Bolt.new（$25 / 月起，按需开）— 7 分：非程序员出「好看的全栈原型」最快的两个（已核实：Lovable Pro $25，学生 5 折；Bolt 年付约 $18 / 月）。与 Antigravity 的分工是「它出脸，Antigravity 出骨」。Argon 没提的坑：Lovable 的 credits 烧得凶，一个完整 MVP 能吃 150–300 credits，而 Pro 只含 100 / 月。等她做需要卖相的产品前台时再开，不常驻。
  • 即梦 AI（姐姐线）：剪映生态的国内短剧工作流（图 / 视频 / 配音一体），与 Kling 并列姐姐的国内直连选项，试产时同题对比。
  • Exa / Felo（线头）：程序化抓取高质量网页数据 / 跨语种跨信源研究整合——未深核，进线头库，等真有需求再验。

Recovered by the blind review and verified after the fact: OpenRouter (8.5) — one key, 500+ models, provider prices passed through plus a 5.5% top-up fee; it replaces model subscriptions, never agent products. Lovable and Bolt (7) — the fastest pretty-prototype builders, rented on demand, with a credit-burn warning Argon omitted. Jimeng joins Kling on the sister's China-direct bench. Exa and Felo go to the leads file, unverified.

12. 结论

结论

法力 = 在役用满 + 异族冗余 + 专长补位。其余都是收藏欲。

下一步只有一件事是确定的：Claude Pro 开了之后，她的系统第一次有常驻的「第二双眼睛」。其余的格子，按 §8 的账本节奏一格一格点亮——每点亮一格，都要能说清它接管了哪类活。

Power equals paid gear fully used, plus a foreign-family backup, plus specialists filling real seats — everything else is collecting. One move is certain: Claude Pro gives her system its first permanent second pair of eyes. Every slot after that gets lit one at a time, each with a named job.
