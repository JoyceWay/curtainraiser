1. 两层学习法：深学 vs 印象层

学习法

  • 深学只做想学的，一次 ≤3 个；固定早上时段，做完汇报验收。
  • 其余一遍 + 一句话印象卡：它是什么、什么时候用、在哪找。
  • 判断标准：连着手头真项目（单词卡、案例、网站、Odyssey、Vibe 项）→ 深学；否则印象。
  • 慢变量深学（loop、context、eval、RAG 原理）；快变量印象层（工具版本、API、模型名），用时再查。
  • 印象层是碎片，不限量、不打分，每月清一次进存档。

Deep-learn at most three things; everything else gets one skim plus a one-sentence impression card. Slow-changing ideas go deep; fast-changing details stay in the impression layer.

2. Agent 打底：模型 + 循环 + 工具

概念

  • 模型单用 = 一句话进、一句话出，没记忆、没手。
  • Agent = 模型 + 循环 + 工具：循环是计划→调工具→看结果→修正计划；工具就是手。
  • Function Calling = 模型决定调哪个工具；MCP = 工具的通用插头标准。
  • 什么时候用 Agent：多步骤、要外部信息、要动手做的事；问个问题、聊个天、想个主意不用。

Agent = model + loop + tools. Use it for multi-step work that needs outside information or doing, not for a question.

3. 蓝标 Under review 是怎么回事

平台知识

  • Under review = X 在审核蓝标资格：订阅后、或改名字 / 头像 / handle 后的重新审核。
  • 审核期间功能照常用（文章照发），缺的是蓝标加成（回复排序），不是被限流。
  • 审核期间别再改资料：改名字、头像、简介可能重置计时。
  • 通常几天恢复；换头像那次几个小时就好了。

Under review costs the badge boost, not baseline reach. Don't touch your profile until the badge returns.

4. 单 agent 文章的口径点

文章口径

  • "~2x 更快" = 一个未具名客户，不是跨客户基准。
  • 55,000 token 砍 85% 以上 = Anthropic 文档里的例子，不是通用数字。
  • Vals 研究结论、Provencher 判断 = 第三方，不是 Anthropic 的结论。
  • 工具定义超过 ~30–50 个会退化；Claude Code 系统提示词砍 80% 以上。

Four caveats to keep straight: single-customer 2x, doc-example token cut, third-party Vals and Provencher, tool-count degradation past thirty to fifty definitions.
