2. Prompt 铁律

Prompt

你不指定的，AI 就自己猜。语言、颜色、字数——想要什么就写什么。比如英文 prompt 不会自动生成中文网站，必须写：All page content must be bilingual: Simplified Chinese primary, English secondary.

Iron rule of prompting: what you don't specify, the AI guesses. Spell out everything.

3. 网页三件套

HTML/CSS

HTML 是骨架：决定页面上有什么。CSS 是衣服：决定长什么样。JS 是动作：决定点了会发生什么。

HTML is the skeleton, CSS the clothing, JS the behavior.

4. CSS 三行

HTML/CSS

max-width: 680px 限宽，内容不铺满全屏。margin: 0 auto 居中（center）。padding 留白（whitespace）。

Three lines that shape a page: constrain width, center it, breathe with padding.

5. 查色号

HTML/CSS

Google 直接搜 #XXXXXX，色卡马上出来。DeRonin 站配色：背景 #FAF7F1 暖纸色，文字 #2A2A28 墨灰，点缀 #A8894F 哑光金。

Look up any hex code by Googling it. DeRonin site palette: warm paper, ink gray, matte gold.

6. Git 三件套

Git

git init -b main：在文件夹里初始化一个仓库，主分支叫 main。从这一刻起，Git 开始盯着这个文件夹。

git add -A：把所有文件放进暂存区——就是告诉 Git："这些，我要打包了。"

git commit -m "备注"：正式打包成一个版本。备注写清楚这次干了什么，以后随时能回到这个版本。

The git trio: init a repo on main, stage everything, commit a version with a clear message. You can always come back to any version.

7. GitHub 中转站模型

Git

我的文件夹 ⇄ GitHub（中转站）⇄ 你的文件夹。git 走的不是"传文件"，是"对账本"——两边各自记账，push / pull 就是对账。

走来走去的文件（网站本身）：index.html 骨架内容、styles.css 样子、log/*.html 每篇日志、README.md 说明书、.nojekyll 让 Pages 原样发布。

不走的：我的后台（流量账本、文章包、图片素材）不上 GitHub；Antigravity 的 scratch 目录是草稿纸，push 后才进中转站。

GitHub 独家记的：Pages 开关和部署记录、仓库设置、commit 公账——跟本地 .git 一样，但这份丢不了，是你电脑坏了之后的救命账。

Git doesn't pass files around — it reconciles ledgers. GitHub is the cloud ledger you can always recover from.

8. Shell：电脑的翻译官

Shell

Shell 就是你跟电脑说话的语言，终端是它的嘴。每一行都是"动词 + 对象"：cd 文件夹 = 去那儿，git push = 推上去。

cd 不是机器语言——机器语言是 0 和 1。Shell 把你的人话翻成操作系统能懂的指令：你 → shell → 操作系统 → 0 和 1。

常用 12 个：pwd 我在哪、ls 有啥、cd 进去、mkdir 新建文件夹、git status/add/commit/push/pull/log 记账五件套、rm 删除（不进回收站，用前先问）。

DOS 是亲戚：Mac 现在用 zsh，你 2003 年学的 cd、mkdir 照用，二十多年没变。唯一区别：当年 dir 现在叫 ls。

Shell is how you talk to the computer. Code says what to do; shell is how you command it. An evergreen skill.

9. Git 名字的由来

Git

作者 Linus Torvalds（Linux 之父）起的。Git 在英式俚语里是"蠢货"——他原话："我是个自大的混蛋，所有项目都以自己命名。"名字是自嘲，工具是认真的。

"Git" is British slang for "idiot" — Linus named it after himself, as a joke.
