活动海报母题

活动海报：一个高饱和色块，或一圈插画边框 —— 热闹和信息兼得。

← 返回设计分析

D04-12026-10-11 · justfont 活动海报

開工字在講：字體×品牌

2024-03-04 活动。橘色几何块打底，黑大字（字體）/（品牌）对角排布，嘉宾竖排。

#EC692F 橘 #ffffff 白
能偷的
  • 高饱和单色块 + 黑字 = 活动海报万能公式，不用配图
  • 括号括字成符号：（字體）/（品牌）远看也认得
  • 中英混排拉层级：中文大字 + 英文小字，信息不打架
不要学的

橘色满铺小图上刺眼——大字要更大，细节别指望缩略图。

D04-22026-10-11 · 活動頭圖

好漢玩字 2018

中央绛红大字 + 两侧满幅彩绘插画边框（虎/山水），竖排英文点缀。

#3D3A39 深底
能偷的
  • 两侧插画边框 = 节庆感：中间给标题，两边负责热闹
  • 竖排英文小字点缀，中英混排不抢戏
不要学的

插画边框只适合大图；标题字要够大，小图下只剩红字。
