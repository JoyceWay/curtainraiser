D01-12026-10-11 · 封面

Loops and Graphs 课程封面

暖米纸底 + 焦橙唯一强调色 + 三字体分工。好在"纪律"，不是堆料。

#F4EFE9 纸底 #1F1F1F 墨 #D96C33 焦橙 #8B6FC4 紫 #A9BE6E 豆绿 #6FAEDE 天蓝
字体
角色推断可商用替代
眉题等宽家族（中）IBM Plex Mono + 宽字距
标题紧缩型 neo-grotesk（中高）Inter Tight Bold（Google Fonts 免费）
说明人文主义 mono（中）IBM Plex Mono / JetBrains Mono
能偷的
  • 三色纪律：纸底 + 墨 + 一支强调色，强调色只点动词和动作点
  • 三字体分工：追踪大写眉题 / 粗黑标题 / 等宽说明 = 课程感
  • 四角极细线图标 + 点线，治大留白显空
  • 一图一句话：图解只讲一个动作
  • 小人脚下椭圆投影，扁平插画零成本出空间感
不要学的

图解区四色不进文字区；标题字距收紧只适合 ≤4 词短标题，中文照搬会糊。

D01-22026-10-11 · 图解 · Muse 改版定稿

A perfect loop on the wrong shape

原稿色彩纪律松了（5 个强调色）。按三刀重画：2 色纪律、金句回底部、网格分区。顺序未动：1错形 → 2对形 → 3金句。

#F4EFE9 纸底 #C09070 陶土 #1F1F1F 墨
字体
角色推断可商用替代
眉题等宽/无衬线加宽字距（中）IBM Plex Mono + 宽字距
标题紧缩型 neo-grotesk（中高）Inter Tight Bold（Google Fonts 免费）
说明人文主义 mono（中）IBM Plex Mono / JetBrains Mono
能偷的
  • 网格纸 = 工程草稿感，和 engineering 主题气质锁死
  • 对比结构：同一批 unit，上错下对——"结构 > 努力"万能版式
  • 金句卡：mono + 关键词高亮，一句话 takeaway
  • 眉题小横线 + 追踪大写，章节感强
改版三刀
  • 收敛到 2 色：陶土管标题/金句，一支动作色管 split/merge/gate，unit 全白——颜色 = 语义
  • 金句回底部放大收框：顺序 1错形 → 2对形 → 3金句 不动
  • 网格浓度分区：标题区淡、图解区深；注释 "you approve the last step" 加粗
