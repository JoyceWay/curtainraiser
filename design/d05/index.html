字体发布母题

字体发布：字形自己会说话。提案四件套齐了，就是一张发布封面。

D05-12026-10-11 · 字型提案

粿仔 /kué-á/ 字型提案

纸纹底 + 巨大"粿仔" + 台罗拼音 + 一句话卖点"寬扁厚實、香Q美味" + 署名。

#E5E4DE 纸纹
能偷的
  • 字型提案四件套：大字 + 读音 + 一句话卖点 + 署名，齐了就是提案封面
  • 纸纹底显质感：比纯白多一分手作感
  • 卖点借味觉词（香Q美味）：字体提案用食物语言，好记
不要学的

无。提案封面范本。

D05-22026-10-11 · justfont 字體發布

激燃體 #激燃體2020

爆炸构图："激燃體"斜排压中央，黄闪电 + 碎石 + 网点。

#E86848 激燃红 #0808C8 宝蓝
能偷的
  • 字体即海报：被展示的字体做最大视觉锤，字形自己会说话
  • 红蓝黄 + 网点 = "燃"的标配语法，情绪一步到位
  • 话题标签进画面：既是标题又是传播位
不要学的

这套只适合"燃"主题；日常用就是车祸。
